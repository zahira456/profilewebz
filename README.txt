1. index.html — Halaman Utama

Halaman ini menjadi pintu masuk utama website. Isinya menampilkan gambaran singkat tentang Anda atau layanan yang ditawarkan. Biasanya terdiri dari:

Header / Navigation untuk berpindah ke halaman lain.

Hero section berupa judul besar, deskripsi singkat, dan tombol ajakan (CTA).

Ringkasan konten seperti preview portofolio atau pengantar singkat tentang diri Anda.

Footer berisi informasi dasar seperti hak cipta, link cepat, serta media sosial.

File ini berfungsi sebagai tampilan pertama yang dilihat pengunjung dan memberikan kesan awal mengenai keseluruhan website.

2. about.html — Halaman Tentang

Halaman ini menjelaskan informasi mengenai diri Anda atau profil pemilik website.

Isi umumnya meliputi:

Penjelasan siapa Anda.

Latar belakang atau pengalaman.

Keahlian utama.

Foto profil atau ilustrasi.

Tujuan utamanya adalah memberi pemahaman kepada pengunjung mengenai identitas pemilik website secara lebih mendalam.

3. portofolio.html — Halaman Portofolio

Halaman ini menampilkan hasil karya, proyek, atau pengalaman kerja Anda secara visual.

Struktur umumnya berisi:

Daftar proyek dalam bentuk kartu (card) atau grid.

Gambar atau preview proyek.

Judul proyek dan deskripsi singkat.

Kadang disertai link menuju detail atau demo proyek.

Halaman ini berfungsi menunjukkan kemampuan dan hasil kerja yang sudah Anda selesaikan.

4. kontak.html — Halaman Kontak

Halaman ini menyediakan cara agar pengunjung dapat menghubungi Anda.

Bagian-bagian utamanya:

Formulir kontak berisi:

Nama

Email

Nomor telepon (sudah dibuat hanya bisa angka)

Pesan

Informasi kontak tambahan seperti:

Alamat email

Media sosial

Tujuan halaman ini adalah mempermudah komunikasi antara Anda dan pengunjung website.

5. css/custom.css — File Gaya Tampilan (CSS Custom)

File ini berisi seluruh aturan styling yang mengatur tampilan website.

Isinya mencakup:

Pengaturan warna, font, layout.

Styling untuk header, footer, card, modal, form, dan elemen lainnya.

Responsivitas untuk tampilan mobile.

Modifikasi ukuran modal agar konsisten.

Fungsi utama file ini adalah memastikan semua halaman memiliki tampilan yang seragam dan sesuai desain yang diinginkan.

6. Folder images — Folder Penyimpanan Gambar

Folder ini berisi semua gambar yang digunakan di website, seperti:

Foto profil

Gambar portofolio

Logo atau ikon

Ilustrasi halaman

Folder ini memungkinkan pengelompokan aset visual agar tetap rapi dan mudah dikelola.
