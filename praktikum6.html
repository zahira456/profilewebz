    • Laporan Praktikum 6 Laravel

    Pendahuluan

    Pada praktikum ini dilakukan proses instalasi dan pengenalan framework Laravel. Laravel merupakan framework PHP berbasis MVC yang digunakan untuk membangun aplikasi web.

    Tujuan Praktikum

    • Memahami instalasi Laravel
    • Memahami penggunaan Composer
    • Menjalankan project Laravel
    • Mengenal struktur dasar Laravel

    Alat dan Bahan

    • XAMPP
    • Composer
    • Git
    • Visual Studio Code
    • Node JS dan NPM

    Langkah-Langkah Praktikum

    1. Install XAMPP

    XAMPP digunakan sebagai web server lokal untuk menjalankan project Laravel.

    2. Install Composer

    Composer digunakan untuk mengelola dependency pada Laravel.

    3. Membuat Project Laravel
    composer create-project laravel/laravel project-laravel

    Perintah tersebut digunakan untuk membuat project Laravel baru.

    4. Menjalankan Laravel
    php artisan serve

    Setelah perintah dijalankan, Laravel akan berjalan pada localhost.

    Hasil Praktikum

    Laravel berhasil diinstall dan dijalankan menggunakan localhost. Project juga berhasil diupload ke GitHub dan dideploy ke hosting menggunakan GitHub Actions.
